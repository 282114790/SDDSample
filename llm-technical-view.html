01. MODEL ARCHITECTURE

Decoder-Only Transformer 架构

现代主流大语言模型（如 GPT-4, Llama 3, Claude）几乎全部采用 Decoder-only 架构。 与原始的 Encoder-Decoder 模型（Attention Is All You Need, 2017）不同，这些模型具有自回归 (Autoregressive) 特性， 将序列的联合概率建模为条件概率的乘积：

$$ P(w_{1:T}) = \prod_{t=1}^{T} P(w_t | w_{1:t-1}) $$

缩放点积注意力 (Scaled Dot-Product Attention)

这是驱动 Token 之间信息流动的核心机制。对于长度为 \(L\) 和嵌入维度 \(d_{model}\) 的序列：

$$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}} + M\right)V $$
  • Q, K, V: 输入 Embedding 的线性投影 (Linear Projections)。
  • 缩放因子 \(\sqrt{d_k}\): 防止点积数值过大导致 Softmax 进入梯度消失区域。
  • M (Mask): 因果掩码 (Causal Mask，上三角为 \(-\infty\))，确保位置 \(t\) 无法“看到” \(>t\) 的未来信息。
02. IMPLEMENTATION

PyTorch 核心实现

model.py
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class CausalSelfAttention(nn.Module):
    def __init__(self, config):
        super().__init__()
        assert config.n_embd % config.n_head == 0
        # 合并 Key, Query, Value 的线性投影层 (Linear Layer)
        self.c_attn = nn.Linear(config.n_embd, 3 * config.n_embd)
        # 输出投影层
        self.c_proj = nn.Linear(config.n_embd, config.n_embd)
        self.n_head = config.n_head
        self.n_embd = config.n_embd
        # 注册因果掩码 (Causal Mask) 作为 buffer，不作为可训练参数
        # 形状为下三角矩阵，用于遮蔽未来信息
        self.register_buffer("bias", torch.tril(torch.ones(config.block_size, config.block_size))
                                    .view(1, 1, config.block_size, config.block_size))

    def forward(self, x):
        B, T, C = x.size() # Batch, Time(序列长度), Channels(嵌入维度)

        # 计算 query, key, values
        q, k, v = self.c_attn(x).split(self.n_embd, dim=2)
        
        # 变形为多头注意力 (Multi-head Attention) 格式: 
        # (B, T, n_head, head_size) -> (B, n_head, T, head_size)
        k = k.view(B, T, self.n_head, C // self.n_head).transpose(1, 2)
        q = q.view(B, T, self.n_head, C // self.n_head).transpose(1, 2)
        v = v.view(B, T, self.n_head, C // self.n_head).transpose(1, 2)

        # 缩放点积注意力 (Scaled Dot-Product Attention)
        # 矩阵乘法: (B, nh, T, hs) x (B, nh, hs, T) -> (B, nh, T, T)
        att = (q @ k.transpose(-2, -1)) * (1.0 / math.sqrt(k.size(-1)))
        
        # 应用因果掩码 (将未来的位置填充为 -inf，使其在 Softmax 后概率为 0)
        att = att.masked_fill(self.bias[:,:,:T,:T] == 0, float('-inf'))
        att = F.softmax(att, dim=-1)
        
        # 值向量 (Value) 的加权求和
        y = att @ v # (B, nh, T, T) x (B, nh, T, hs) -> (B, nh, T, hs)
        
        # 重新组合多头 (Reassemble heads)
        y = y.transpose(1, 2).contiguous().view(B, T, C)
        return self.c_proj(y)
03. INFERENCE OPTIMIZATION

KV Cache 推理加速可视化

在自回归生成中，计算第 \(N\) 个 Token 的 Attention 需要 \(Q_N\)，以及所有历史的 \(K_{1...N}\) 和 \(V_{1...N}\)。 如果不使用缓存，每一步都需要重新计算之前所有 Token 的 K 和 V 矩阵。 KV Cache 技术通过在显存 (VRAM) 中驻留这些向量，将每步计算复杂度从 \(O(N^2)\) 降低到 \(O(N)\)（总复杂度 \(O(N^2)\)）。

04. ALIGNMENT PIPELINE

RLHF (基于人类反馈的强化学习)

1. SFT (有监督微调)

在高质量的“指令-回复”对数据上微调预训练模型，学习指令遵循能力。

Loss = -log(P(response|prompt))
2. Reward Modeling (RM)

训练一个独立的标量模型（Reward Model）来预测人类偏好，为生成的回答打分。

Loss = -log(σ(r(yw) - r(yl)))
3. PPO / DPO

使用强化学习优化策略 \(\pi\)，在最大化奖励的同时，通过 KL 散度约束防止偏离原模型。

max E[r(x,y) - β log(π/π_ref)]
